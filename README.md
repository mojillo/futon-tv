# Futon TV

**Manga reader for Android TV and Google TV**

Futon TV is an unofficial fork of [Futon](https://github.com/AppFuton/Futon) (itself a fork of [Kotatsu](https://github.com/KotatsuApp/Kotatsu)) adapted for big-screen reading with remote control and D-pad navigation. Read manga and manhwa on your TV with full remote support.

## Install

Download the latest APK from [GitHub Releases](https://github.com/mojillo/futon-tv/releases) and sideload it to your Android TV device.
